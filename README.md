# Social Studio v1.1

Mobile-first Social Studio frontend for Ocean State Spice & Tea Merchants.

## v1.1 highlights
- App-style bottom navigation: Create, Results, Projects, Tools
- One primary screen at a time to reduce scrolling
- Fixed horizontal page drift/sideways scrolling on mobile
- Recent Projects moved to its own screen
- Photo tools moved to a dedicated Tools screen
- Original/Edited toggle instead of two full-size stacked previews
- Compact collapsible Reel/photo guidance
- Separate photo and video upload choices
- “Choose Video” recommended for best iPhone quality
- In-app rear-camera recording beta with high-resolution/30fps preferences and widest available zoom request
- Preserve Reality photo workflow retained
- v1.0 recent projects migrate forward

The Firebase backend is unchanged from v1.0 for this release.
