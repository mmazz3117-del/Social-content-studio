# Social Studio v1.3 — Save & Share + Clean Reel Export

Frontend-only update.

- Uses the native device share sheet when supported for finished Post, Story, Reel, edited photos, and prepared packages.
- Avoids claiming a file was saved when the browser only requested a download.
- Reel rendering is now clean by default: AI hook/overlay text remains visible in Social Studio as reference only and is not burned into the exported Reel.
- Users can add their preferred Reel text when posting.
- No Firebase redeploy is required.
